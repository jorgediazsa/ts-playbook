# TypeScript Senior Roadmap — Basic to Advanced

This repository contains a comprehensive, senior-focused TypeScript curriculum divided into three main modules:

### 1. [Basic (Core Philosophy & Foundations)](./basic/)
- **01 — TypeScript Mental Model**
- **02 — Top, Bottom & Special Types**
- **03 — Type Inference & Control Flow**
- **04 — Interfaces vs Type Aliases**
- **05 — Enums, Const Enums & Union Patterns**
- **06 — Compiler Configuration as Architecture**

### 2. [Intermediate (Mastering the Type System)](./intermediate/)
- **07 — Generics Deep Dive**
- **08 — Type Guards & Exhaustiveness**
- **09 — Index Signatures & Key Manipulation**
- **10 — Utility Types Internals**
- **11 — Declaration Files & Module Augmentation**

### 3. [Advanced (Type-Level Programming & Architecture)](./advanced/)
- **12 — Conditional Types**
- **13 — Advanced Mapped Types**
- **14 — Template Literal Types**
- **15 — Nominal Typing & Branded Types**
- **16 — Function Typing at Scale**
- **17 — Large-Scale Architecture Patterns**
- **18 — Migration & Integration Strategies**

## Requirements
- Node.js (recent LTS)
- pnpm

## Install
```bash
pnpm install
```

## Run
```bash
pnpm test
pnpm typecheck
pnpm verify
```

## Exploring Exercises
Check the [roadmap.md](./roadmap.md) to explore individual concepts and navigate to their specific directories. Each topic contains `README`, `src`, `tests`, and `type-tests`.
