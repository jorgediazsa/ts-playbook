# TypeScript Senior Roadmap — Basic Topics 1–3

This repo contains three senior-oriented TypeScript modules:

- **01 — TypeScript Mental Model**
- **02 — Top, Bottom & Special Types**
- **03 — Type Inference & Control Flow**

## Requirements
- Node.js (recent LTS)
- pnpm

## Install
```bash
pnpm install
```

## Run
```bash
pnpm test
pnpm typecheck
pnpm verify
```

## Notes
- Runtime behavior is tested with **Vitest**.
- Type-level requirements are enforced via `pnpm typecheck` using `*.type-test.ts` files.
